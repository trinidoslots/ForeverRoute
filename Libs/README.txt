Libraries bundled with ForeverRoute (as in RestedXP Guides):

  LibStub, CallbackHandler-1.0   - standard World of Warcraft addon libraries.
  HereBeDragons-2.0 and HereBeDragons-Pins-2.0 by Nevcairiel (Hendrik Leppkes),
  BSD license (see https://www.wowace.com/projects/herebedragons).
  They show the step numbers on the world map and the minimap.

The two HereBeDragons files were copied from the libs folder of RestedXP Guides
v4.11.34. Only the library names (ForeverRoute-HBD-...) and the map pin template
name were changed, so ForeverRoute's copy never clashes with the copy that
RestedXP or Questie load.
